# 配色主题参考

## 两种来源

- 内置配色：用户从现有风格包中选择。
- 参考图配色：用户上传一张图片，系统提取 5-8 个可复用颜色和视觉气质。

## 配色合同

参考图必须转成明确的色彩职责：背景色、表面色、主文字、次文字、主强调色、辅助强调色、状态色和禁用组合。

## 使用规则

- 只学习颜色关系、明暗比例、饱和度和气质，不照抄参考图版式或内容。
- GPT-5.6 负责把参考图整理为配色合同；生成时还必须把参考图原文件直接作为 Image2 的视觉输入，不能只传文字色值。
- 参考图模式的版式选择只控制信息组织、留白和节奏，风格包中的蓝、金、红、紫等配色描述一律忽略。
- 同一套 PPT 的背景、标题、正文、卡片和重点数字必须遵守同一配色合同。
- 强调色只用于真正的重点，不能每个元素都高亮。
- 图表系列色要能区分且保持可读性。
- 文字与背景必须有足够对比，不能为了贴近参考图牺牲阅读。
- 没有参考图时使用内置配色，不制造随机新颜色。
- Image2 参考图接口失败时必须明确报错，不能静默退回纯文字生图。
