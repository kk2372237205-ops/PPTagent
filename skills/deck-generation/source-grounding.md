# 资料读取与事实依据

## 原则

- 用户可以一次上传多份 PDF、Word、Excel、PPT、文本和图片，不要求用户预先整理。
- 系统先保留原文件，再按页、工作表或幻灯片切分为可定位的资料片段。
- ChatGPT 负责整理资料，但不能把几十份文件简单拼接成一篇摘要，也不能只看压缩摘要。
- 每个数字、日期、人物、荣誉、结论和原话都必须能回到“文件名 + 页码/工作表/幻灯片”。
- 找不到可靠材料时明确标记资料不足，不得补造。

## 按页匹配

1. 先理解用户给定的页面标题、目的、小标题和约束。
2. 从全部资料片段中召回候选，再让 ChatGPT 选择真正相关的证据。
3. 一个页面只拿与该页主题直接相关的材料，不能为了填满版面塞入无关内容。
4. 同一条证据可以支持多页，但每页应有不同结论和表达任务。
5. 输出内容包时保留 evidence_ids，并在界面展示对应文件和位置。

## 禁止项

- 禁止把没有来源的常识包装成用户资料。
- 禁止改写关键数字的单位、时间范围、统计口径。
- 禁止因摘要而丢掉表格中的极值、比例、排名和备注。
- 禁止把图片中看不清的文字当作确定事实。
