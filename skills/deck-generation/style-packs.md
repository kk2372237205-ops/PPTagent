# Style Packs

风格包给用户看起来是简单按钮，给模型时必须展开成完整约束。

本文件只用于“内置配色”模式，同时规定颜色与版式。生成 PPT 高级版选择“参考图配色”时不得读取本文件，必须改用 `advanced-layout-profiles.md`；风格包 ID 在参考图配色模式下只作为版式语言的兼容键，不能向模型泄漏蓝金、白绿、黑金等颜色含义。

本文件的小节集合必须与 `lib/employee-deck-packs.mjs` 的 `DECK_STYLE_PACKS` 完全一致；`npm run verify:check` 里的 `scripts/check-style-packs.mjs` 会逐 ID 比对，缺一个就报错。新增或删除风格包时先改 `.mjs`，再同步本文件。

## 渲染路线（所有风格包共用，先读这一条）

**画面默认真实写实。风格包只决定配色、版式、母题和字体气质，不决定渲染方式。**

用户要的是"严谨、实事求是"的观感，所以：

- **写实是默认**：设备、工具、线缆、机械结构、零部件、自然环境、作业场地、工艺流程，都要画得像真实存在的实物——真实材质、自然光、诚实纹理、轻微颗粒。
- **禁止**：卡通、扁平矢量吉祥物、Q 版、厚描边描边插画、纸片剪贴、clip art。
- **也要避免"假精致"**：不要影棚灯光、不要商业摆拍、不要过度磨皮的塑料感——那比扁平更容易显得假。
- **图解页例外**：当页面讲机制、结构、流程、数据时，改用精细技术图解（均匀细线、测量式间距、直接标注 5–8 处），**不是**卡通示意图。

**工程、装备、检测、政务、科研这类正式汇报中，母题只保留制图语言**：
细线、网格、刻度、标注、剖切线、尺寸线、角标——这些能增强"严谨感"。
**不要**扫描线、光轨、数据粒子、星点、半透明玻璃卡片、发光边缘——这些会削弱严谨感，且是典型 AI 味来源。

**配色职责照旧**：无论走写实还是图解，页面的背景、文字、线条、几何和强调色都必须服从该风格包的配色（或参考图配色合同）。**写实不等于放开配色。**

## 高级版正文的插图与版式轮换

本节只在高级版且使用内置配色时生效；参考图配色由 `advanced-layout-profiles.md` 提供同一套版式规则。

- “插图”是可独立替换的完整照片类图片框，不是流程图、时间线、图表、图标或装饰几何。
- 普通正文只要有设备、材料、工艺、环境或应用情境，默认至少安排两张不同插图：一张主视图加一张不同的细节、工序或语境图；不能把同一场景裁两次凑数。
- 有两个或三个并列的具名案例、阶段或应用时，用相应两到三张插图，各自服务一个内容块。纯数据表、严格事实图表或已经完整标注的技术机制图可以少于两张。
- 相邻正文页不得重复“左边图解/卡片，右边一张竖图”的轮廓。可在主图加细节、三联故事带、照片锚点流程、前后对照双图、全景加证据带、图解加照片嵌图、纵向图片脊柱之间按内容轮换。
- 所有插图仍在同一次 Image2 整页生成中重绘；最多三张照片类图片框，必须是完整硬边框，不能渐变融入背景。


## blue-gold-tech：蓝金科技

- palette（固定色值）：背景 #071B33、表面 #0E315A、主文字 #F4F8FC、辅助文字 #A9C5DC、强调蓝 #2E8CE6、强调金 #D7AA43。
- layout：左上标题、右侧主视觉、底部进度线、半透明数据卡片。
- motifs：扫描线、网格、光轨、数据粒子、细线图标。
- typography：粗标题、窄字距科技感副标题、清晰短句。
- forbidden：不要紫色霓虹、不要卡通、不要红色政务风。

## white-green-tech：白绿科技

- palette（固定色值）：背景 #F6FAF7、表面 #FFFFFF、主文字 #163F35、辅助文字 #587069、强调绿 #2F8F74、浅绿 #9CCDB9。不得自行加入海军蓝、金色或黄色。
- layout：大留白、圆角卡片、轻量页眉、底部步骤条。
- motifs：点云、薄线网格、生态科技叶片、浅色 HUD。
- typography：清爽、专业、适合项目路演和技术方案。
- forbidden：不要黑金奢华、不要重阴影、不要赛博霓虹。

## black-gold-business：黑金商务

- palette（固定色值）：背景 #111315、表面 #1D2226、主文字 #F4EFE4、辅助文字 #B9B2A6、强调金 #C9A45A、暗金 #7D6943。
- layout：强对比封面、数据卡片、纵向分栏、精致边线。
- motifs：金属细线、低调光泽、金融/商业质感纹理。
- typography：稳重、高端、克制。
- forbidden：不要卡通插画、不要绿色环保风、不要廉价渐变。

## minimal-academic：极简学术

- palette（固定色值）：背景 #FFFFFF、表面 #F7F7F7、主文字 #17191C、辅助文字 #5C6268、强调黑 #17191C、分隔灰 #CED1D4。不得使用蓝色、金色或彩色强调。
- layout：大留白、清晰标题、少量图表、严格网格。
- motifs：细线、标注、简洁图解、论文式结构。
- typography：克制、清楚、阅读优先。
- forbidden：不要复杂背景、不要强烈光效、不要密集装饰。
