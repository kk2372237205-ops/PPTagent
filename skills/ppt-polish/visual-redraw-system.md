# PPT Polish Visual Rebuild System

Use these rules for every PPT polish page.

- Rebuild one complete 16:9 presentation page, never a browser screenshot, chat UI, poster mockup, or unrelated artwork.
- Preserve the source meaning. Keep supplied names, dates, figures, units, and required labels readable. Do not invent factual claims, sources, or metrics.
- Keep a clear reading order and practical safe margins. Prefer a small number of strong visual ideas over dense micro-cards and decorative clutter.
- Do not force a stock palette or style pack. Establish one restrained visual language from the source content, selected protection requirements, and any saved page-level prompt clip; keep that language consistent across the deck.
- Make cover and ending pages emotionally stronger with limited text. Make content pages readable first, varying the composition only when it helps the information.
