# PPT 美化提示词

这里存放美化 PPT 后台执行脚本实际读取的画面重绘规则。

- `visual-redraw-system.md`：所有美化任务共用的页面重绘边界、信息保真要求和封面/正文/结尾规则。
- 目标风格的颜色与版式仍以 `../deck-generation/style-packs.md` 为唯一真源，不在这里复制风格包 ID 或配色，避免生成 PPT 与美化 PPT 发生漂移。

业务边界：确认美化后，系统默认把整份 PPTX 在本机转换为按页 PNG，供员工核对与后续流程使用。默认不会把这些图片传给 Image2。只有用户明确选择“用原稿页指导 Image2 重绘”且服务端开启独立试验开关时，才会逐页上传对应原稿图；这属于 AI 重绘，不能承诺文字、logo、照片或图表像素级不变。
