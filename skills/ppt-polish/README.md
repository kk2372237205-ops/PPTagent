# PPT 美化提示词

**这里目前没有规则文件，这是刻意的。**

2026-09-30 owner 决定：美化链路的提示词只由用户自己写的内容组成，不再掺任何我们预设的画面规则。
原因：那些规则会和用户的指令直接打架——用户说"文字图片内容不变、用蓝白科技风"，规则却说
"不要锁定风格、每页必须有 25% 以上主导插图并出血、默认写实摄影、封面结尾文字极少、降低文字密度"。
模型会听更长更具体的那一方，于是就"不听话"了。

## 现在每页的提示词只有三段

1. **用户要求**（最高优先级）：整套方向 + 本页要求 + 用户勾选的保护项 + 本次返工指令；
2. **本页原有文字**：从 PPTX 抽出来的文字，只作为"这页讲什么"的参考；
3. **本页位置**：第几页 / 共几页、来源文件、前后页文字（仅供连贯性参考）。

代码位置：`scripts/workers/ppt-polish/ppt-polish-worker.mjs` 的 `slidePrompt()`。
要恢复旧规则看 git 历史（提交 `c484d36` 及更早：被删掉的 `visual-redraw-system.md`
与整套 hard requirements 都在那里）。

## 业务边界（未变）

确认美化后，系统默认把整份 PPTX 在本机转换为按页 PNG，供员工核对、点选页面和填写逐页要求。
该图片集不会自动交给 Image2；它只用于本地流程与人工选择。
