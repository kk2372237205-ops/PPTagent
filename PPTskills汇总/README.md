
## 三条使用纪律

1. **不要只写风格名。** 写 "Swiss style" 模型会自由发挥；必须把线宽、色数、是否渐变、视角写死。这是"同一套风格包出来的图质量波动大"的唯一原因。
2. **每一页都要带面积合同。** 不写面积，模型默认把插图缩成装饰角标。最小可用的一句是：
   `The illustration is the single largest element and occupies at least 45% of the canvas.`
3. **禁令必须配替代品。** 只写 "never use card grids" 会让模型用"什么都不画"来满足你。每写一条禁令，同段里必须给出可执行的替代版式。
