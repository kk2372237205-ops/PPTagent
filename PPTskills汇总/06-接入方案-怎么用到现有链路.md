## 一、先看这个：三个改动，收益最大

按照"改动量 ÷ 收益"排序，前三名如下。

### 🥇 第一名：给 `visual-identity.md` 加一个字段，激活一条已在代码里沉睡的通路

**改哪**：`skills/deck-generation/visual-identity.md`（**只改这一个 Markdown 文件，不动代码**）

**为什么**：`scripts/deck-generation-worker.mjs:3012` 已经在读这个字段：

```js
image_language: identity.image_language || identity.imagery || {},
```

`:3576` 已经在要求图片模型遵循它：

```
- Use the global_style_fingerprint consistently for palette, typography feel,
  background, header/footer, card chrome, motifs, grid, and image language.
```

但 `visual-identity.md` 的 JSON 结构里**没有这个字段**，所以它永远是 `{}`（详见 `05-根因诊断` RC-2）。

**改法**：在 `visual-identity.md` 的 JSON 结构里加 `image_language`，并写明提取要求：

```json
{
  "style_name": "",
  "palette": [],
  "background_system": "",
  "layout_system": "",
  "card_system": "",
  "typography_feel": "",
  "motifs": [],
  "image_language": {
    "style": "",
    "stroke": "",
    "fills": "solid flat fills only",
    "gradients": "forbidden",
    "shadows": "forbidden",
    "color_count": 4,
    "view": "",
    "subject_rule": "concrete nouns from the page content; abstract nouns are not valid subjects",
    "forbidden_motifs": []
  },
  "header_footer_rules": "",
  "white_space_rules": "",
  "forbidden": []
}
```

**预期效果**：图片模型从"没有插画语言"变成"有明确插画语言"，直接改善"插图很假"与"整套不统一"。

**风险**：低。只加字段，不改任何既有字段语义。**唯一副作用**是 GPT-5.6 每次要多产出一点 JSON，成本可忽略。

### 🥈 第二名：把"插图占多大"写成数字

**改哪**（4 个 Markdown 文件）：

| 文件 | 改什么 |

## 三、建议的落地顺序

```
第 1 步（1 个文件，半天）
  └─ P0-1  visual-identity.md 加 image_language
     → 跑一个 2 页小任务，对比出图
     → 如果插图质量明显提升，说明 RC-2 判断正确，继续

第 2 步（4 个文件，1 天）
  └─ P0-2/3/4/5  面积合同 + 默认值反转 + 禁令配替代品
     → 同一个 2 页任务重跑，对比
     → 重点看：主视觉面积是否 ≥35%、是否还有那 5 张假照片缩略图

第 3 步（4 处代码，1 天）
  └─ P1-9/10/11/12
     → 跑 5-6 页任务，看整套节奏

第 4 步（快速版专项）
  └─ P1-13  快速版补正向插图指令

第 5 步（产品决策）
  └─ P2 全部 + P3 全部
```

**每一步都要**：
1. 在 `codex/<功能名>` 分支上做；
2. 改完跑 `npm run verify`（`tsc` + `eslint --max-warnings 11` + `prisma validate` + `next build`）；
3. **用小页数任务验证**（`skills/README.md` 的维护原则就是这么写的："改技能后，用小页数任务验证，不要一次跑大任务"）；
4. 出图后用 `03-插图手册` 第七节的自检清单打分；
5. 更新 `docs/current-project-memory.md`。

## 四、验证方式（怎么知道改好了）

| 指标 | 现在（实测） | 目标 |
| --- | --- | --- |
| 正文页主视觉面积 | **0%**（案例 B） | ≥ 35% |
| 单个画面元素最大占比 | ~5% | ≥ 30% |
| 通用装饰图标数量 | **9 个**（案例 B，尽管提示词要求 0） | ≤ 2 个，且每个都承载信息 |
| 假照片/糊图缩略图 | 5 张（案例 B） | 0 张（要么不画，要么画成明确非写实的插画） |
| 无语义占位图形 | 3 组灰色横条（案例 C） | 0 |
| 整套插图面积曲线 | 封面 ~55%，正文 0%，正文 40% | 相邻页差异 ≤ ±25%，无低于 25% 的正文页 |

**打分方法**：把出图按 `03-插图手册` 第七节的 10 项逐条打勾，任何一项不过就回到对应提示词条目（T-x）修正。
